# Sistema de Reembolsos

Aplicação web para gerenciamento financeiro desenvolvida em **Django**, com HTML, CSS e JavaScript.  
O sistema foi criado para atender as necessidades de uma **ONG voltada para educação**, permitindo organizar e controlar solicitações de reembolso de forma simples e eficiente.

---

## 🛠 Tecnologias Utilizadas

- **Back-end:** Django (Python)
- **Front-end:** HTML5, CSS3, JavaScript
- **Arquitetura:** Aplicação monolítica (front-end e back-end integrados)

---

## ✅ Funcionalidades

- Autenticação de usuários
- Registro de solicitações de reembolso
- Aprovação e controle de status das solicitações
- Interface responsiva para melhor experiência do usuário

---

## 🌍 Contexto

Este sistema foi desenvolvido para uma **ONG de educação**, visando simplificar o processo de reembolso e melhorar a gestão financeira.
Este projeto é privado e desenvolvido para uso interno de uma ONG. Por isso, não está disponível para ser acessado.
